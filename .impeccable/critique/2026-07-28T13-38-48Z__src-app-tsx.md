## What is Working Well

1. **Typography hierarchy**: Outfit on headings + Plus Jakarta Sans on body + JetBrains Mono on data/code creates three distinct reading registers. The sidebar app name, section titles, and stats page header all feel more intentional.
2. **Contrast and interaction states**: Hover backgrounds and destructive action buttons are now consistently shade-matched. Disabled form states use `opacity-50` across all modals, creating visual coherence.
3. **Table signal layer**: Stage-aware urgency, clean date formatting, and decluttered company cell make the main list view genuinely scannable.
4. **Resilience**: Cloud sync failures produce visible, actionable toasts rather than silent data resets.

## Remaining Opportunities

### [P2] Pipeline board drag-and-drop has zero discoverability
**What**: The `GripVertical` icon is the only hint that cards are draggable. No instruction text, no cursor change, no empty-state hint.
**Fix**: Add a single line of helper text under the board header: *"Drag cards between columns to advance their stage"* — visible only when the board is not empty, dismissible after first drag.

### [P2] No keyboard shortcut to open Add Application modal
**What**: `Ctrl+K` opens search, but there is no shortcut to open the Add modal (conventional: `N` or `A`).
**Fix**: Add `keydown` handler in `App.tsx` for `n` key (when no input is focused): trigger `setIsAddModalOpen(true)`.

### [P3] Remaining `gray-on-color` hover-state warnings (8 items)
**What**: All remaining detector warnings are ghost-button hover backgrounds — only visible during mouse interaction.
**Fix**: Use fully shade-matched hover colors (e.g., `text-rose-700 hover:bg-rose-50` → `text-rose-800 hover:bg-rose-100`) to clear the detector floor completely.

### [P3] `Plus Jakarta Sans` body font still flagged as overused
**What**: Detector still flags `index.css` line 5.
**Fix**: `Plus Jakarta Sans` is a reasonable body face and reads well at this scale. The more important distinction is that Outfit now leads all headings. Consider this acceptable unless you want to make a stronger typographic statement.
